# 供应链语义可识别评测集：研究合同（草案冻结 v0）

## 1. 研究目的

本评测集回答一个问题：异构融合模型的提升是否来自真实的来源关系，而不是额外参数量、计算量或动态自由度。

评测对象是国家—周级供应链风险预测。每个样本包含运营、事件/新闻、贸易网络传播和时间背景，目标是预测下一周是否出现异常集装箱活动。

当前阶段只使用已经暴露的开发年份。2026-09-07 至 2027-03-01 的未来留出期及其标签不进入评测集设计、模型选择或阈值选择。

## 2. 数据单位与语义关系

- 样本单位：国家 `c`、截止周 `t`。
- 输入窗口：截止周之前连续 12 周。
- 结果标签：下一周供应链异常风险。
- 运营证据：PortWatch 集装箱靠港活动及其历史变化。
- 本地事件证据：与国家 `c` 直接关联的 GDELT 新闻统计。
- 外部事件证据：其他国家或全球背景中的 GDELT 新闻统计。
- 网络传播证据：按照冻结的 WITS 2019 贸易关系，将伙伴事件传播到国家 `c`。
- 时间证据：月份、季度和周序关系。

真实语义关系不是模型生成的标签，而是由数据构建过程确定的关系：同一国家、同一周、真实贸易边以及正确时间顺序。

## 3. 核心数学对象

记真实样本为

`X_ct = {O_ct, E_ct^own, E_t^other, sum_j W_cj E_jt, T_t}`，

其中 `O` 是运营证据，`E` 是事件证据，`W` 是冻结贸易网络，`T` 是时间背景。模型输出下一周风险分数 `f(X_ct)`。

比较两个参数量和计算量匹配的模型：

- `f_sem`：能够读取真实国家、时间和网络关系；
- `f_null`：结构、参数量和训练预算相同，但只读取固定随机或置换后的关系编码。

在真实数据上的语义增益定义为：

`G_real = Score(f_sem, D_real) - Score(f_null, D_real)`。

在语义被破坏后的相对增益为：

`G_destroy = Score(f_sem, D_destroy) - Score(f_null, D_destroy)`。

主要识别量是差中之差：

`I_sem = G_real - G_destroy`。

语义机制只有在 `G_real > 0` 且 `I_sem > 0` 时才获得支持。对 NLL 和 Brier 使用统一的“越大越好”方向转换。单纯出现 `Score(D_real) > Score(D_destroy)` 只说明模型使用了该关系，不能证明这种使用带来净收益。

## 4. 固定语义破坏

所有破坏保持样本数、特征维数、边际分布和模型容量不变。

1. **国家配对破坏**：在同一周内，将本地事件证据分配给另一个国家。
2. **时间对应破坏**：在同一国家内用预先固定的非零周移位替换事件证据。
3. **网络关系破坏**：保持贸易图的度和权重分布，置换伙伴身份后重新聚合伙伴事件。
4. **来源身份破坏**：保持五类来源的数值不变，固定置换来源标签。

置换规则在训练前由种子生成，不根据模型结果选择。

## 5. 供应链压力条件

这些条件用于测量边界，不用于重新选择模型。

- Missingness：屏蔽一个真实来源。
- Conflict：令事件证据与运营趋势方向冲突。
- Reliability asymmetry：降低一个来源的信噪比，同时保持其他来源不变。
- Temporal misalignment：逐步增加事件与运营证据的时间错位。
- Network contamination：将高风险伙伴证据错误传播到无真实贸易联系的国家。

鲁棒性和语义必要性分开报告。语义破坏导致下降说明模型依赖关系；在缺失和冲突下下降较小才说明模型稳健。

## 6. 数据划分与泄漏约束

- 按时间切分训练、验证和测试，禁止随机混合未来周。
- 归一化、缺失值填补、阈值和早停只在训练/验证期拟合。
- 同一国家相邻窗口跨边界时保留既有一周 purge 和 12 周前缀排除规则。
- 已暴露年份只用于开发评测；未来留出期保持封存。
- 任何语义破坏都不能读取测试标签。

## 7. 固定对照

1. 强基础模型 TabM。
2. V1 轻量条件化模型，作为 preliminary baseline。
3. 与候选方法参数量、深度、训练预算匹配的 generic null。
4. 真实关系候选模型。
5. 同一候选模型的国家、时间、网络和来源语义破坏版本。

模型首先在真实数据上比较，再报告差中之差 `I_sem`。不能通过挑选最有利的破坏类型宣布成功。

## 8. 指标与判定

- 主要任务指标：AP。
- 概率指标：NLL、Brier。
- 排序指标：AUC。
- 业务指标：Top-K 风险恢复、周级最高风险预警精度与召回。
- 统计单位：时间折与随机种子的配对结果；同时报告 win/tie/loss、最差折和分层 bootstrap 区间。

两道硬门：

1. **容量门**：真实关系模型稳定优于 matched-capacity null。
2. **语义门**：破坏真实关系后，候选模型相对 null 的优势显著缩小，即 `I_sem > 0`。

最小有意义效应阈值暂不填写。它将在不读取未来标签的前提下，根据开发折方差和业务预警成本进行一次功效分析后冻结。

## 9. V1 可迁移内容与边界

可以迁移的设计原则：

1. **近恒等、受限条件化**：V1 从原模型严格恢复点开始训练，复杂动态条件化多次表现不稳定。后续候选应保持可控扰动和明确的原模型恢复点。
2. **乘法交互作为条件作用形式**：现有结果支持乘法版本相对简单相加有小幅优势，尤其体现在概率质量。它可以作为候选的起始交互形式，但不能被称为已经证实的语义机制。
3. **学习到的共享变换方向**：保持秩和范数但随机化变换方向会损害多项指标，说明学习方向有功能作用。低秩只作为限制容量和计算的参数化；“低秩是核心原因”没有得到支持。

只能迁移为实验协议的内容：

- validation-based enable/disable 可减少负迁移，但属于模型选择规则，不是融合机制证据。
- NLL/Brier 必须与 AP 一起报告，因为 V1 的主要信号更接近概率质量改善。

不能迁移为既定机制的内容：

- sample-specific prompt 与 transform 的正确配对不是稳定结论；
- continuous temporal drift、异构程度单调增益、task-aligned M 核心解释、多轴协同均未成立；
- 更强动态化、STTF、关系张量和 butterfly 不能作为默认升级路线。

## 10. 停止规则

- 候选不能通过容量门时，停止该候选，不添加补救模块。
- 候选通过容量门但不能通过语义门时，只能称为更强预测模型，不能称为语义融合方法。
- 只有两道门均通过，才允许进入外部 benchmark 和未来留出期验证。
- 不使用服务器上尚未揭示的 TabZilla/TabArena 结果修改本合同。

## 11. 下一项可执行工作

1. 从现有开发面板生成只含真实来源映射的审计清单。
2. 实现四种固定语义破坏的数据视图，先验证行数、时间和边际分布不变。
3. 用 TabM、V1 和一个参数匹配 null 做最小 smoke test，检查评测量 `I_sem` 能否计算。
4. 在 synthetic 数据上验证评测协议：当标签确实依赖关系时应通过语义门；当标签只依赖容量时应拒绝。
5. 协议通过后再讨论一个新的融合算子。
